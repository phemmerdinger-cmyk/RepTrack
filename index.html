How connecting works

1. Register an application in WHOOP's Developer Dashboard. 2. Deploy RepTrack's backend to an HTTPS host with your WHOOP client ID, secret, and redirect URL. 3. Open this website on that host and tap Connect WHOOP to authorize access. Never paste a client secret into this page.
